The idea

What one agent learns, every agent knows.

A chat ends, you switch tools, a teammate picks up the work — and the context is gone. With Brainkeep your agents write down what matters as they go and read it back before they start, in any client and for your whole team.

How it works

Save, revise, recall.

  1. 1remember

    Save

    Agents record decisions, discoveries and progress on their own, guided by a short protocol the server sends — no long prompts.

    remember(
  kind: "decision",
  topic: "payments-idempotency",
  content: "Use idempotency keys…"
)
  2. 2correct

    Revise

    A change appends a revision; history is never overwritten. Stale edits are refused, so two agents can’t silently overwrite each other.

    correct(
  id: "mem_8f2c",
  expected_revision: 2,
  content: "…and on refunds too"
)
  3. 3context

    Recall

    Before work, any agent pulls compact context for the project — in any client, for anyone you share it with.

    context(
  project: "checkout-api",
  compact: true
)

Features

A small server with a serious memory.

Written in Rust

Native Rust, end to end.

One binary with no runtime and no garbage collector, embedded SQLite and the web panel built in. Nothing else to install: no Node, no Python, no database server. It runs even on a Raspberry Pi.

Language
Rust, no GC
Storage
Embedded SQLite
Panel
Built into the binary
Runs on
macOS · Linux · Raspberry Pi

Revisions and authorship

Every memory keeps its full history, with verified authorship on each revision.

Built for teams

Invite people by email, share projects read-only or read-write, revoke access instantly. Google sign-in over OAuth.

Small context footprint

Compact responses and a short memory protocol, so agents save on their own without bloating the prompt.

Safe by default

Passwords, keys and tokens are rejected before storage. Private files and per-user request limits.

A panel for people

Search, filters, history, diffs and live updates. Edit with conflict handling, archive and restore.

Backups and migrations

Consistent backups on a systemd timer and schema migrations with snapshots, so upgrades are safe.

Self-host

Your memory lives on your machine.

Run it locally for yourself in a minute, or on any Linux host with systemd behind HTTPS for your whole team — a Raspberry Pi is enough.

  • Local, single userDownload a release and connect your agents.
  • Server for a teamUsers, sharing, Google sign-in and backups.

macOS (Apple silicon) and Linux. Windows is not supported yet.

# 1 · Download and verify
v=0.1.1; t=brainkeep-$v-aarch64-macos
repo=https://github.com/aledepaoligampel/brainkeep
base=$repo/releases/download/v$v
curl -fLO $base/$t.tar.gz && curl -fLO $base/SHA256SUMS
grep " $t.tar.gz\$" SHA256SUMS | shasum -a 256 -c

# 2 · Install
tar -xzf $t.tar.gz && mkdir -p ~/.local/bin
cp $t/brainkeep ~/.local/bin/

# 3 · Run and connect Claude Code
~/.local/bin/brainkeep --data-dir ~/.brainkeep serve &
claude mcp add brainkeep -- \
  ~/.local/bin/brainkeep --data-dir ~/.brainkeep mcp
