La idea

Lo que aprende un agente, lo saben todos.

Termina un chat, cambiás de herramienta, otra persona retoma el trabajo… y el contexto se pierde. Con Brainkeep tus agentes anotan lo importante mientras trabajan y lo leen antes de empezar, desde cualquier cliente y para todo tu equipo.

Cómo funciona

Guardar, revisar, recordar.

  1. 1remember

    Guardar

    Los agentes registran decisiones, hallazgos y avances por su cuenta, guiados por un protocolo breve que envía el servidor. Sin prompts largos.

    remember(
  kind: "decision",
  topic: "payments-idempotency",
  content: "Usar claves de idempotencia…"
)
  2. 2correct

    Revisar

    Cada cambio agrega una revisión; el historial nunca se pisa. Las ediciones desactualizadas se rechazan, así dos agentes no se sobrescriben en silencio.

    correct(
  id: "mem_8f2c",
  expected_revision: 2,
  content: "…y también en reembolsos"
)
  3. 3context

    Recordar

    Antes de trabajar, cualquier agente trae el contexto compacto del proyecto, desde cualquier cliente y para cualquiera con quien lo compartas.

    context(
  project: "checkout-api",
  compact: true
)

Funciones

Un servidor chico con una memoria en serio.

Escrito en Rust

Rust nativo, de punta a punta.

Un binario sin runtime ni recolector de basura, con SQLite embebido y el panel incluido. No hay nada más que instalar: ni Node, ni Python, ni un servidor de base de datos. Corre hasta en una Raspberry Pi.

Lenguaje
Rust, sin GC
Almacenamiento
SQLite embebido
Panel
Incluido en el binario
Corre en
macOS · Linux · Raspberry Pi

Revisiones y autoría

Cada memoria conserva todo su historial, con autoría verificada en cada revisión.

Pensado para equipos

Invitá por email, compartí proyectos en solo lectura o lectura y escritura, y revocá el acceso al instante. Inicio de sesión con Google vía OAuth.

Poco contexto

Respuestas compactas y un protocolo de memoria breve: los agentes guardan solos sin inflar el prompt.

Seguro por defecto

Contraseñas, claves y tokens se rechazan antes de guardarse. Archivos privados y límites por usuario.

Un panel para personas

Búsqueda, filtros, historial, diffs y actualizaciones en vivo. Edición con manejo de conflictos, archivar y restaurar.

Backups y migraciones

Backups consistentes con un timer de systemd y migraciones de esquema con snapshots, para actualizar sin miedo.

Autoalojado

Tu memoria vive en tu máquina.

Corrélo en local para vos en un minuto, o en cualquier host Linux con systemd detrás de HTTPS para todo tu equipo. Alcanza con una Raspberry Pi.

  • Local, un usuarioDescargá un release y conectá tus agentes.
  • Servidor para un equipoUsuarios, permisos, inicio con Google y backups.

macOS (Apple silicon) y Linux. Windows todavía no está soportado.

# 1 · Descargar y verificar
v=0.1.1; t=brainkeep-$v-aarch64-macos
repo=https://github.com/aledepaoligampel/brainkeep
base=$repo/releases/download/v$v
curl -fLO $base/$t.tar.gz && curl -fLO $base/SHA256SUMS
grep " $t.tar.gz\$" SHA256SUMS | shasum -a 256 -c

# 2 · Instalar
tar -xzf $t.tar.gz && mkdir -p ~/.local/bin
cp $t/brainkeep ~/.local/bin/

# 3 · Iniciar y conectar Claude Code
~/.local/bin/brainkeep --data-dir ~/.brainkeep serve &
claude mcp add brainkeep -- \
  ~/.local/bin/brainkeep --data-dir ~/.brainkeep mcp
